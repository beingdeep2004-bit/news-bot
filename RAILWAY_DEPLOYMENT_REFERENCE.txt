TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Bot doesn't respond to commands
  → Check: Logs tab for errors
  → Verify: BOT_TOKEN is exactly correct
  → Verify: CHAT_ID is exactly correct
  → Check: Bot is added to your Telegram chat/channel
  → Fix: Redeploy (click Redeploy button)

❌ Build fails
  → Check: Build logs for Python errors
  → Common: Missing dependency (shouldn't happen)
  → Fix: Restart deployment

❌ Digests don't send at scheduled time
  → Check: Logs around 08:00, 13:00, 19:00 IST
  → Verify: Railway timezone is correct
  → Fix: Restart deployment

❌ Logs say "Connection refused"
  → Cause: API temporarily unavailable
  → Fix: Bot retries automatically
  → Check: Logs in 5 minutes - should recover

❌ Memory/CPU errors
  → Cause: Free tier overloaded
  → Fix: Upgrade to Starter ($5/month)
  → Check: Railway dashboard for resource usage
